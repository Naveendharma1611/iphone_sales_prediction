# 📱 iPhone Sales Data Analysis & Prediction

## 📌 Project Overview
This project focuses on analyzing iPhone sales data to understand sales trends, customer demand, and revenue patterns. Using historical sales data, we perform exploratory data analysis (EDA) and build a predictive model to forecast future iPhone sales.

The goal of this project is to demonstrate **data analysis, visualization, and basic machine learning skills** using Python.

---

## 🎯 Objectives
- Analyze historical iPhone sales data
- Identify sales trends over time
- Understand the relationship between price, demand, and revenue
- Predict future iPhone sales using machine learning
- Present insights in a clear and business-friendly manner

---

## 🧩 Dataset
- **Type:** Inbuilt / simulated dataset
- **Features included:**
  - Year
  - iPhone Model
  - Units Sold
  - Price
  - Revenue
- **Note:** The dataset is created for learning and demonstration purposes and closely resembles real-world sales data.

---

## 🛠️ Tools & Technologies Used
- **Programming Language:** Python  
- **Libraries:**
  - Pandas – Data manipulation
  - NumPy – Numerical operations
  - Matplotlib & Seaborn – Data visualization
  - Scikit-learn – Machine learning model
- **Environment:** Jupyter Notebook / VS Code

---

## 📊 Exploratory Data Analysis (EDA)
During EDA, the following analyses were performed:
- Year-wise sales trend analysis
- Revenue growth visualization
- Comparison of different iPhone models
- Correlation between price and units sold

Key visualizations include:
- Line charts for sales trends
- Bar charts for model-wise comparison
- Heatmaps for correlation analysis

---

## 🤖 Machine Learning Model
- **Problem Type:** Regression
- **Model Used:** Linear Regression
- **Target Variable:** Units Sold
- **Input Features:** Year, Price

### Model Evaluation
- Train-test split used for validation
- Model performance evaluated using:
  - R² Score
  - Mean Squared Error (MSE)

---

## 📈 Results & Insights
- iPhone sales show a consistent growth trend over the years
- Premium models contribute significantly to total revenue
- Price has a noticeable impact on units sold
- The prediction model provides a reasonable estimate for future sales
